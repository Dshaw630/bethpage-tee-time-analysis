# Bethpage State Park Tee Time Booking Automation Analysis
Analysis of Bethpage State Park tee-time data (2021–2025) focusing on the prevalence of automated booking abuse, and the effectiveness of recent booking rule changes in reducing such behavior.

## Background & Motivation
This analysis is heavily inspired by [episode 945 of the No Laying Up Podcast](https://nolayingup.com/podcasts/no-laying-up-podcast/945-nlu-special-projects-the-mystery-behind-why-bethpage-is-always-booked), in which Kevin Van Valkenburg investigates the seemingly herculean task of securing a tee time at Bethpage State Park, a public facility with five 18-hole golf courses, including the lauded Black Course, host to this year’s Ryder Cup. As highlighted in the podcast, one major contributing factor to the inaccessibility of these tee times is the extensive deployment of automated booking software by individuals and resellers to scrape up entire lots of tee times fractions of seconds after release time, before most users could even load the booking web page. In April 2025, a few months after the podcast aired, Bethpage announced some booking policy changes designed to discourage automated booking, including a booking fee, increased no-show fees, and monthly cancellation limits. The focus of this analysis will be trying to understand the extent to which automation was at play in the years leading up to these rule changes, and to gauge their effectiveness in discouraging users from using technology to abuse the system.

It is important to note here that just a few days after the dataset this analysis will use was requested via a New York State FOIL request, Bethpage announced a more robust set of rule changes set to take effect in October 2025. The centerpiece of this second change was the implementation of two-factor authentication during the booking process, which will likely be much more, if not completely, effective in stopping automated booking. It may be interesting to make a similar FOIL request in the fall of 2026 to add fresh data into the analysis and compare behavior between all three eras of booking behavior.
